# Espelho público do LEON

Cópia dos artefatos **assinados** que a central serve sem licença. Serve de plano B: quando a central não responde, o agente instalado busca a atualização aqui e continua funcionando.

Todo arquivo é conferido pelo cliente contra o `release-manifest.json`, que é assinado (Ed25519). Um arquivo trocado aqui não passa na verificação.

Não há segredo, licença nem código-fonte neste repositório.
